# Voorbeelden van transcripties en harmonie-correcties

Deze map bevat drie representatieve voorbeelden (pianomuziek van Gerrit Koele):

1. **Psalm 85**
2. **De Lofzang van Maria**
3. **U zij de glorie**

## Inhoud van deze map

- `readmes/`: toelichtingen per stuk met directe links naar de bijbehorende YouTube-uitvoeringen.
- `mp3/`: de van YouTube gedownloade audio.
- `ongecorrigeerd/`: de rechtstreekse MusicXML-uitvoer van de transcriptie (stap 2).
- `gecorrigeerd/`: de MusicXML-uitvoer na herzetting van de binnenstemmen volgens klassieke harmonieleerregels (stap 5).
